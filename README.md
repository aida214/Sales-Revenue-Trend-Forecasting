# Sales & Revenue Trend Forecasting

## Objective

Forecast future sales using historical sales data to help businesses plan inventory, staffing, and other resources.

## Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Prophet
* Scikit-learn

## Project Steps

* Data cleaning and preprocessing
* Sales trend and seasonality analysis
* Time-series forecasting
* Feature engineering using promotional and holiday information
* Model training and evaluation
* Backtesting
* 30-day sales forecasting
* Forecast uncertainty analysis

## Results

The forecasting model was used to predict future sales based on historical patterns, promotions, holidays, and seasonal trends. Model performance was evaluated using backtesting, and a 30-day sales forecast was generated to support business planning and decision-making.
